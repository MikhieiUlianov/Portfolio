HTML5 is the backbone of the web — it defines the **structure** and **content** of every web page.  
With HTML, you describe what appears on the screen: headings, paragraphs, images, links, forms, and much more.

For example, you should understand code like this:

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Hello HTML</title>
  </head>
  <body>
    <h1>Welcome to HTML5</h1>
    <p>This is a paragraph of text.</p>
    <a href="https://developer.mozilla.org">Learn more</a>
  </body>
</html>
```
