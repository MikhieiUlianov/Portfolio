TypeScript is a **superset of JavaScript** that adds static typing.  
It helps you catch errors **before** running your code and makes it easier to work on large projects.

For example:

```ts
function greet(name: string): string {
  return `Hello, ${name}!`;
}

const user: string = "Alice";
console.log(greet(user));
```

Started learn: **2025-06-01**

Learn more about it [**here**](https://www.typescriptlang.org/).
